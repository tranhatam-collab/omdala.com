- Any command or code executed through OMCODE has the same permissions as your browser process.

- **ANY COMMAND** entered in the terminal — including commands generated by AI — executes with your user privileges.

The "Apply Code" feature allows AI-generated code to be written directly into your files. By using this feature, you acknowledge:

- AI-generated code may contain **bugs, security vulnerabilities, or destructive logic**.
- Clicking "Apply" will **overwrite** the existing file content without automatic backup.
- We strongly recommend using Git to version-control your code before applying AI suggestions.
- OMCODE does not validate, lint, or sandbox applied code before writing to disk.

### 1.4 File System Modification Risk
